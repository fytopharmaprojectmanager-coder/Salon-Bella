# Salón pre psov Bella – ukážkový web

One-page web pre Salón pre psov Bella (Martina Benku 51B, Malacky).

- `index.html` – celá stránka (HTML + CSS, bez frameworku)
- `assets.txt` – zoznam fotiek a videa z Higgsfieldu; pri každom nahratí ich GitHub Actions stiahne a zmenší (WebP, MP4 720p)
- Úvodná fotka a video: Higgsfield (AI). Ostatné fotky: Unsplash (voľná licencia, unsplash.com/license). Ideálne vymeniť za reálne fotky salónu.

Výmena fotky: nahraj vlastnú do `img/` a v `index.html` prepíš cestu, alebo zmeň URL v `assets.txt`.
